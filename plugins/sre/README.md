# sre

Skills for keeping on-call sustainable: SLOs. Built from public Google SRE sources (each skill lists its sources with dates). Every production-changing step is a proposal for a human to approve.

| Skill | Subcategory | Use it to |
|---|---|---|
| `create-slo` | Reliability | Define SLOs and multiwindow, multi-burn-rate alerts |

Related skills in other plugins: `runbook` (documentation), `diagnose` (programming).
